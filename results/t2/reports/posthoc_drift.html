PERISIM post-hoc drift analysis

Exploratory · not pre-registered · aggregates only

Exploratory, post hoc. Added on 2026-10-28 at the lead's request, after the transport analyses; not pre-registered, no decision rule. The frozen INSPIRE metric (shapes gj, weights wj, α, k) is kept and only its case base is swapped for each site's own patients (the pool of the transport stage; same test set, labels and k). Each variable's values (INSPIRE's bins, categories, 0 / 1) are points in the metric. ICE: test stays moved along every value through the frozen geometry (blind where gj is flat). Re-deformation: the points of one variable freed and fitted to the site (case base and queries alike, everything else frozen), by gradient on a smoothed version of the same kNN, patient-level leave-one-out, ridge 20 towards INSPIRE's points; evaluated with the real kNN on the test set. Continuous variables get a separate 'missing' value (INSPIRE imputes the median). INSPIRE is the control: the same fits at home (in-sample: the metric was read from all of INSPIRE). The class components of a point are anchored to INSPIRE's by the ridge (distances alone do not fix them), so read them as directions, not as calibrated log-odds.
